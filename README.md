## 🌟 Giới Thiệu Tổng Quan

**Ứng dụng Ôn luyện & Đấu trường Lớp học Lịch Sử & Địa Lý THCS** là giải pháp công nghệ giáo dục hiện đại, phục vụ giảng dạy tương tác trên lớp cho Giáo viên và ôn luyện hiệu quả cho Học sinh từ Lớp 6 đến Lớp 9.

Ứng dụng được thiết kế theo phong cách giao diện **Glassmorphism truyền thống kết hợp hiện đại**, tích hợp công nghệ **kết nối thời gian thực WebRTC qua Mã QR** giúp học sinh tham gia thi đấu từ điện thoại di động mà **không cần cài đặt phần mềm** hay **cùng mạng Wi-Fi**.

## 🔥 Tính Năng Nổi Bật

### 🏁 1. Đấu Trường Linh Thú Việt Nam (Classroom Game Arena)
- **Đường Đua Linh Thú Trực Quan**: Thứ hạng và điểm số của các đội được visualize dưới dạng cuộc đua Linh thú tiến về **Vạch Đích 🏁**.
- **Đội Nhóm Linh Thú Đặc Hữu Việt Nam**:
  - 🐃 **Đội Trâu Vàng**: Biểu tượng cần cù, dũng mãnh và văn hóa lúa nước Việt Nam.
  - 🦅 **Đội Chim Lạc**: Biểu tượng chim thần trên mặt trống đồng Đông Sơn huyền thoại.
  - 🦌 **Đội Sao La**: "Kỳ lân Châu Á" - Loài thú quý hiếm đặc hữu dãy Trường Sơn.
  - 🐒 **Đội Voọc Quần Đùi**: Voọc mông trắng quý hiếm bậc nhất Việt Nam.
- **Kết nối Mã QR Thời Gian Thực**: Giáo viên chiếu màn hình máy tính lên máy chiếu, học sinh bật camera điện thoại quét mã QR để chọn đội và thi đấu trực tiếp.
- **Bảng điểm Kép trên Điện thoại**: Hiển thị song song **Điểm Cá Nhân** (+100đ mỗi câu đúng) và **Điểm Đội Nhóm** cập nhật theo thời gian thực.

### 📚 2. Ngân Hàng Câu Hỏi Tư Liệu & Ngữ Cảnh Chuẩn GDPT 2026
- **Đầy Đủ 3 Dạng Thức Trắc Nghiệm Mới**:
  1. *Trắc nghiệm nhiều lựa chọn (MCQ)*.
  2. *Trắc nghiệm Đúng/Sai 4 ý độc lập (True/False)*.
  3. *Trả lời ngắn / Tính toán Địa lý (Short Answer)*.
- **Tư Liệu & Ngữ Cảnh Thực Tế**: Mỗi câu hỏi đều đi kèm trích dẫn văn bản lịch sử, bảng số liệu địa lý thực tế giúp học sinh phát triển tư duy thay vì học thuộc lòng.
- **Công Thức & Lời Giải Chi Tiết**: Phân tích chi tiết công thức tính toán (mật độ dân số, cơ cấu %, gia tăng tự nhiên, năng suất lúa, chuyển đổi hải lí/km...).
- **Hình Ảnh Minh Họa Nét Cao**: Tích hợp bộ sưu tập hình ảnh bản đồ, sông ngòi, vùng núi, vùng kinh tế và di sản văn hóa Việt Nam với cơ chế tự động khôi phục fallback thông minh.

### ⏱️ 3. Thi Thử Mô Phỏng 45 Phút 2026
- Tạo đề thi ngẫu nhiên 20 câu chuẩn cấu trúc bộ ma trận mới.
- **Thuật toán chấm điểm Đúng/Sai không tuyến tính**: 1 ý đúng (0.1đ), 2 ý đúng (0.25đ), 3 ý đúng (0.5đ), 4 ý đúng (1.0đ) theo chuẩn Bộ Giáo dục & Đào tạo.

### 📊 4. Báo Cáo Tiến Độ & Streak Học Tập
- Tự động ghi nhớ câu hỏi chưa làm đúng để luyện tập lại.
- Thống kê tỉ lệ đúng chi tiết theo từng khối lớp (Lớp 6, 7, 8, 9).
- Theo dõi chuỗi ngày học tập đều đặn (Streak Days).

## 🚀 Hướng Dẫn Cài Đặt & Chạy Cục Bộ

### 👨‍🏫 Dành cho Giáo viên (Khởi động 1-Click không cần gõ lệnh)
Nhấp đúp chuột vào file:
```cmd
Chay_App_LichSu_DiaLy.bat
```
Hệ thống sẽ tự động bật máy chủ và mở trình duyệt web lên ngay lập tức!

---

### 💻 Dành cho Lập trình viên (Developer Setup)

1. **Clone repository về máy**:
   ```bash
   git clone https://github.com/kien-ngtt196/the-study-project.git
   cd the-study-project
   ```

2. **Cài đặt thư viện dependencies**:
   ```bash
   npm install
   ```

3. **Chạy máy chủ phát triển (Development Server)**:
   ```bash
   npm run dev
   ```
   Sau đó mở trình duyệt tại: `http://localhost:5173`

4. **Đóng gói sản phẩm (Production Build)**:
   ```bash
   npm run build
   ```
